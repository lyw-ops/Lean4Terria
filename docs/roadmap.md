# Lean4Terria 开发路线图

目标是用 Lean 4 复现《泰拉瑞亚》。游戏机制和物品以桌面版 1.4.5.8 的普通模式为基准，优先查官方 Wiki，边界行为用同版程序核对。每个版本用 Lean 路线重放与 macOS 实际操作验收。

按原版方法逐段手工转译。可独立比较的规则用相同输入逐项对照，依赖时间、随机数和碰撞的行为保留这些输入再比较。骷髅王的药水和红心掉落已对照 `NPC.DoDeathEvents_DropBossPotionsAndHearts` 核对两次抽样的全部组合。

## 接下来的版本

| 版本 | 任务 | 验收 |
| --- | --- | --- |
| **地牢入口仪式** | 将已对照的刷新门槛接入石碑、两名弓手和两名信徒 | 实测石巨人和骷髅王胜利后到达地牢、仪式成员刷新及战斗。 |
| **神庙掉落用途** | 接入石巨人武器、饰品、甲虫外壳与蜥蜴蛋的用途 | 从正常装备、合成和宠物入口测试，核对存档。 |
| **困难模式装备** | 继续接入史莱姆皇后装备相关机制 | 从正常装备入口验证效果和存档。 |
| **地狱物品与钓鱼** | 完成暗影箱物品效果、发光蘑菇任务、钓鱼药水配方及钓出物品的其余用途 | 用原版物品来源完成钓鱼、开箱和任务交付。 |
| **天气与世界事件** | 接入风、暴雨、血月，以及相关敌怪和钓鱼鱼获 | 在正常世界时钟中触发事件，检查外观、敌怪与存档延续。 |

## v0.1 的游玩目标

玩家出生在工作台附近，身上有一把基础镐。沿地表找到洞口，挖铜矿，回工作台做一把铜镐。铜镐能开采深处的水晶矿。玩家也可以用挖到的方块搭台阶，开辟自己的路线。挖出第一块水晶就是首版的进度目标，之后仍可以继续建造和探索。

- **地图**暂定为 256 × 128 格。世界由种子生成，包含地表、石层、洞穴、铜矿和水晶矿。发布时提供一个从出生点到水晶都能走通的试玩种子。
- **操作**采用 A/D 移动、空格跳跃、鼠标左键挖掘、右键放置、数字键选择快捷栏、E 使用附近的工作台。选中的物品、数量以及合成缺少的材料都能在游戏里看到。
- **交互**只作用于玩家附近的格子。挖掘成功后材料直接进背包。放置要求目标为空，且新方块与玩家的碰撞盒没有重叠。矿石硬度区分两级镐。
- **呈现**早期版本先用轮廓和颜色区分方块、人物和矿石。当前版从本机《泰拉瑞亚》读取原版贴图，旧版自定义内容映射到相近的原版贴图。

## 技术设计

v0.1 的桌面平台是 Apple Silicon macOS。构建使用 Lake，锁定 Lean 4.35.0 和 raylib 6.2。一小层 C FFI 包装窗口、输入、绘图和音频调用，并在 Cocoa 要求的进程主线程上运行桌面程序。[Lean FFI 文档](https://lean-lang.org/doc/reference/latest/Run-Time-Code/Foreign-Function-Interface/) · [raylib 2D 示例](https://www.raylib.com/examples.html)

### 游戏核心与桌面程序

- **纯 Lean 核心**负责世界生成、角色移动、碰撞、物品和合成。接口形如 `step : GameState → TickInput → GameState`，每次推进一个固定模拟步。核心可单独构建和运行测试，启动时不需要图形库。
- **Lean 桌面程序**读取键鼠，把鼠标位置转换成地图坐标，驱动模拟，再根据状态绘制场景和界面。模拟先以每秒 60 步为目标，渲染随窗口刷新。跳跃和点击这类按下事件保留到下一次模拟步，并只消费一次。C 层封装窗口、输入和绘图调用。
- **数据表示**用 `ByteArray` 存平铺的方块编号，以 `y * width + x` 定位格子，访问前检查边界。角色用轴对齐碰撞盒，分轴处理移动，检查经过的格子以防高速穿墙。世界生成的随机数由种子驱动，重放测试使用同一版本下的种子和逐步输入序列。
- **绘制**先只遍历镜头覆盖的格子，记录试玩时的帧时间。地图扩大后，根据测量结果引入区块存储或缓存。

### 存档与可验证规则

- **存档**先用带版本号的 JSON 保存完整的小地图、玩家和背包。读档检查版本、尺寸、方块数据长度和物品编号，验证通过后才加载。写入时先在同一目录完成临时文件，再替换旧档。读档失败时提示原因并保留原文件。
- **测试**直接调用游戏运行的 Lean 函数。覆盖贴墙和落地、越界挖掘、在玩家身体处放置、背包空间不足、合成失败、固定种子重放和存档往返。
- **首条证明**是「材料不足时，合成函数返回原背包」。证明直接针对游戏调用的 `tryCraft`。挖掘和放置成功时，地图与背包一起更新。背包满时，矿石留在原处。

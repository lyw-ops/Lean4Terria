# Lean4Terria 开发路线图

## v0.1 的游玩目标

玩家出生在工作台附近，身上有一把基础镐。沿地表找到洞口，挖铜矿，回工作台做一把铜镐。铜镐能开采深处的水晶矿。玩家也可以用挖到的方块搭台阶，开辟自己的路线。挖出第一块水晶就是首版的进度目标，之后仍可以继续建造和探索。

- **地图**暂定为 256 × 128 格。世界由种子生成，包含地表、石层、洞穴、铜矿和水晶矿。发布时提供一个从出生点到水晶都能走通的试玩种子。
- **操作**采用 A/D 移动、空格跳跃、鼠标左键挖掘、右键放置、数字键选择快捷栏、E 使用附近的工作台。选中的物品、数量以及合成缺少的材料都能在游戏里看到。
- **交互**只作用于玩家附近的格子。挖掘成功后材料直接进背包。放置要求目标为空，且新方块与玩家的碰撞盒没有重叠。矿石硬度区分两级镐。
- **呈现**先用轮廓和颜色能区分的方块、人物和矿石。试玩路线跑通后再为角色和地形补原创像素素材。
- **后续版本**先做火把、洞穴照明、一个敌人和一把武器，让下洞有准备和风险。再增加生物群系、装备进度和首个 Boss。液体、NPC 和多人联机等玩法在单人循环稳定后另行设计。

## 技术设计

首发平台是 Apple Silicon macOS，构建用 Lake，先以本机已可运行的 Lean 4.35.0 为候选工具链。M0 用 raylib 做窗口和绘图验证，通过后锁定实际通过验证的 Lean 和 raylib 版本。预计用一小层 C FFI 包装所需调用，让项目能独立选择 Lean 版本。[Lean FFI 文档](https://lean-lang.org/doc/reference/latest/Run-Time-Code/Foreign-Function-Interface/) · [raylib 2D 示例](https://www.raylib.com/examples.html)

### 游戏核心与桌面程序

- **纯 Lean 核心**负责世界生成、角色移动、碰撞、物品和合成。接口形如 `step : GameState → TickInput → GameState`，每次推进一个固定模拟步。核心可单独构建和运行测试，启动时不需要图形库。
- **Lean 桌面程序**读取键鼠，把鼠标位置转换成地图坐标，驱动模拟，再根据状态绘制场景和界面。模拟先以每秒 60 步为目标，渲染随窗口刷新。跳跃和点击这类按下事件保留到下一次模拟步，并只消费一次。C 层封装窗口、输入和绘图调用。
- **数据表示**用 `ByteArray` 存平铺的方块编号，以 `y * width + x` 定位格子，访问前检查边界。角色用轴对齐碰撞盒，分轴处理移动，检查经过的格子以防高速穿墙。世界生成的随机数由种子驱动，重放测试使用同一版本下的种子和逐步输入序列。
- **绘制**先只遍历镜头覆盖的格子，记录试玩时的帧时间。地图扩大后，根据测量结果引入区块存储或缓存。

### 存档与可验证规则

- **存档**先用带版本号的 JSON 保存完整的小地图、玩家和背包。读档检查版本、尺寸、方块数据长度和物品编号，验证通过后才加载。写入时先在同一目录完成临时文件，再替换旧档。读档失败时提示原因并保留原文件。
- **测试**直接调用游戏运行的 Lean 函数。覆盖贴墙和落地、越界挖掘、在玩家身体处放置、背包空间不足、合成失败、固定种子重放和存档往返。
- **首条证明候选**是「材料不足时，合成函数返回原背包」。证明直接针对游戏调用的 `tryCraft`。同样，挖掘和放置成功时，地图与背包一起更新。背包满时，矿石留在原处。

## 开发顺序与验收

| 里程碑 | 实现内容 | 验收 |
| --- | --- | --- |
| **M0 · 桌面验证** | Lake 项目、独立的核心构建目标、最小 raylib 接口 | 在 Apple Silicon Mac 上从干净检出按文档构建，打开窗口，按键让方块移动，正常关闭。核心测试在无图形库环境下可运行。 |
| **M1 · 横版地形** | 固定测试地图、移动和跳跃、碰撞、镜头、鼠标选格 | 角色能跑跳、落地和贴墙移动。镜头滚动后，光标仍能选中正确的格子。碰撞测试覆盖地面、侧墙和地图边界。 |
| **M2 · 挖掘与合成** | 挖掘和放置、背包与快捷栏、工作台、两级镐 | 在测试地图挖铜、用铜合成铜镐、用铜镐挖水晶。重复点击、材料不足和背包已满时，地图与物品数量符合规则。 |
| **M3 · 生成与存档** | 种子地图、安全出生点、存档和读档 | 默认试玩种子能跑完整条升级路线。同种子和输入序列重放结果一致。关闭游戏后重开，玩家位置、背包和改过的地形正确恢复。损坏存档会报错并保留原文件。 |
| **M4 · v0.1 试玩** | 可分发的 macOS 构建、操作说明、基础视听反馈 | 从新世界开始，凭游戏里的信息找到洞口，做出铜镐，挖到水晶，保存并继续。记录测试机器、试玩种子和帧时间。 |

### 从 M0 开始

1. 建立 Lake 项目，添加一个能单独运行的纯 Lean 测试目标。
2. 用系统 Clang 链接 raylib。最小窗口循环接通按键状态和矩形绘制，由 Lean 更新矩形坐标。
3. 验证窗口可正常退出，把通过验证的依赖版本、构建命令和运行命令写进 README。

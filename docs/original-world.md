# 原版世界预览

`--original-world` 入口直接读取 Terraria 1.4.5.8 的 `.wld`/`.plr`，按逐段转译的原版逻辑运行。本页从 README 移来，记录已接入的玩法。

解压试玩包后，可用 `./Lean4Terria.app/Contents/MacOS/lean4terria --original-world FILE.wld` 只读加载 1.4.5.8 的普通世界文件。A/D 或方向键移动，空格跳跃，按住左键挖掘。预览中的挖掘发生在内存中。

本地种子 42 的出生区已有从原版运行时采集的地块和墙壁贴图坐标。用下列命令同时加载它们，素材仍从本机《泰拉瑞亚》的 XNB 读取。

```sh
./.lake/build/bin/lean4terria --original-world .lake/original-world/1.4.5.8-seed42/seed42_small.wld \
  --frames .lake/original-framing/1.4.5.8/seed42-frames.json
```

从当前源码构建的预览还可以拾取方块和矿石。按 2 选铜镐，靠近掉落物将其收入背包。用对应数字键选中拾取的泥土、石块或矿石，按左键放置。有铜镐时，可以按住左键将部分已有方块换成手上的方块。Esc 展开或收起背包，关闭窗口退出。

按 **Q** 丢出当前快捷栏整叠物品，收藏的快捷栏物品受到保护。打开背包后，在背包区域外右键可丢出光标上的一叠。手动丢出的物品等待 100 游戏帧后可以拾回。关闭背包时光标物品会尝试放回背包，放不下的余量落在角色身边。

当前源码也支持按 3 选铜斧并按住左键砍普通森林树。砍树干底部会使上方树干和失去支撑的树枝落下。靠近木材和橡实可拾取。

按 Esc 打开背包后，`Crafting` 栏从原版 3,603 条配方中显示当前可以制作的成品。鼠标移到配方栏可滚动列表。点击配方选中，再点击已选的成品格制作。按住左键或右键可以连续制作，按住 Shift 可批量制作。鼠标悬停在原料上可查看替代组。成品放到光标上，点击背包格可放下，或按 Esc 收回背包。工作台两格均需有支撑，站在木平台上按 S 或下方向键可往下穿过平台。

右键打开触达范围内的未上锁箱子，或右键点击梳妆台上排打开储物。带对应钥匙时，右键先解锁，再右键打开。暗影钥匙可重复使用。生物群系箱和沙漠箱需要世界存档中已有世纪之花的击败记录。

打开世界箱或梳妆台的储物界面后，点击 **Rename** 编辑名字。按 Enter 或点击 **Save** 确认，按 Esc 或点击 **Cancel** 取消。名字最多 20 个 UTF-16 码元，留空可恢复容器的默认标题。F5 会把箱名写进世界副本。

已打开的容器右侧提供 **Loot All**、**Deposit All**、**Quick Stack**、**Restock** 和 **Sort Items**。**Restock** 补足随身物品的已有堆叠，符合条件的弹药还可以占用空格。**Sort Items** 合并并分类排列当前容器的物品。关箱后，背包弹药栏下方的 **Sort Inventory** 按钮还会整理钱币和弹药。排序保留收藏格，同类物品的高亮会逐渐消退。也可按住 Shift 左键转移一摞物品，或按住储物格上的右键连续拆分。存钱罐、保险箱、护卫熔炉和虚空保险库可放置并以同样的方式操作。存钱罐需要工作台等桌面支撑。走出触达范围会自动关箱。可以用铜镐回收这些家具，家具也会在失去支撑时掉落。重新放置后可打开同一份个人库存。

拿着世界箱或梳妆台左键放置。鼠标指向箱子的左下格或梳妆台底排的中间格。梳妆台从上排右键打开储物。铜镐可以回收空容器，包括空的上锁箱。装有物品的容器和容器下方的支撑会挡住铜镐。[原版箱子](https://terraria.wiki.gg/wiki/Chests) · [原版梳妆台](https://terraria.wiki.gg/wiki/Dressers)

制作按原版顺序从背包的 58 格、已打开的容器、开启的虚空袋、附近个人存储和其他附近未锁世界箱取料。右键点击背包内的虚空袋可切换启用状态。袋子开启时，随身格放不下的普通掉落和世界箱「全部取出」的余量可以进入虚空保险库。制作栏右侧的原版箱子图标可切换附近取料。

真实世界预览在载入时沉降液体。挖开地形可引导水、岩浆、蜂蜜和微光流动，放下方块可改变流路。选中空桶后，左键点水、岩浆或蜂蜜可取液，选中装满的桶后左键倒出。无底桶可反复倒出对应液体，海绵可反复吸收对应液体。无底微光桶和超强吸水海绵也支持微光。[原版桶](https://terraria.wiki.gg/wiki/Buckets) · [无底桶](https://terraria.wiki.gg/wiki/Bottomless_Buckets)

四种液体使用本机 Terraria 1.4.5.8 的贴图，支持液面与流下段的取帧、半砖与斜坡边缘，以及微光的渐变和闪点。水色随群系、深度、可见范围内已开启的喷泉和世界存档中的血月夜状态变化。打开有半砖溢流或雨云、雪云、岩浆雨云的地图，可以看到按原版路径绘制的瀑布和降水。普通水瀑使用当前水色，微光瀑布有单独的渐变和闪点。画面使用预览光照和静风，瀑布的环境音、地形发光、尘粒和液面波纹滤镜待接入。

无液体装备的角色在水和蜂蜜中有各自的下沉、行走和跳跃规则。头部浸没时，角色上方显示呼吸气泡。呼吸耗尽后开始溺水掉血。蜂蜜提供生命回复，岩浆会伤害角色并使其着火。Classic 角色死亡时掉落部分随身钱币，并在世界出生点复活。死亡满 90 帧后可按跳跃提前复活。掉落物在水、蜂蜜和岩浆中会减速，岩浆会销毁不耐岩浆的低稀有度物品。液体装备、微光嬗变、液体致死的墓碑和入液时的粒子仍待接入。

拿着背景墙物品左键铺墙。墙格需要与已有墙或前景地块相邻，也可以铺在前景地块后面。可以替换已有玩家墙和天然墙的边缘。选中锤子后，左键点按石块等普通方块可在整砖、半砖和四种斜坡之间循环。木平台可在平面、两种楼梯方向和半平台之间循环。第一次挥锤改变形状，按住后可继续敲后面的墙。拆墙后可拾取有掉落的墙物品，相邻的墙会重新取帧。F5 保存方块形状、平台贴图帧和背景墙。祭坛、暗影珠、轨道等特殊目标和墙上附着物的连锁掉落仍待接入。

启动时加上 `--export-world edited.wld`，进游戏后按 **F5** 将地形、背景墙、液体和箱子改动保存到新文件。用 `--player` 读入 Terraria 1.4.5.8 的 Classic 角色可载入其发型、配色、主背包、钱币栏和弹药栏，同时指定 `--export-player` 可在按 F5 时写出角色副本。

```sh
./Lean4Terria.app/Contents/MacOS/lean4terria --original-world input.wld \
  --player input.plr --export-world edited.wld --export-player edited.plr
```

两份副本都能在 Terraria 1.4.5.8 中打开，也可用 `--original-world edited.wld --player edited.plr` 重开。输出位置已有文件时会显示提示。角色副本保留装备、出生点记录、背包和四组个人存储的库存，虚空保险库也保留收藏标记。角色副本还记录生命、死亡次数和复活倒计时，重开时会扣除离线时间。世界副本保留箱名、解锁状态和物品。预览从默认世界出生点开始，可省略 `--player` 使用临时背包。制作采用预览列表。原版制作网格与向导界面、个人存储的召唤投射物和拾取飘字待接入。

原版世界预览可左键挥动木剑，或用铜短剑朝光标刺击。绿史莱姆会跳跃、受击后转为追击，接触会造成伤害和击退。击杀后可拾取凝胶和铜币。用 `--original-world loot-arena.wld --green-slime 2103,307 --player loot-practice.plr` 打开独立练习场，在第 2103 列、第 307 行地块上缘放入一只绿史莱姆。快捷栏第 1 格是铜短剑，第 2 格是木剑。装备战斗加成及完整的持剑动画仍待接入。

普通 `--original-world` 入口会读取时钟、天气、向导和老人，并在 Classic 森林的已覆盖分支自然生成绿史莱姆、兔子、普通鸟和蓝鸦。F5 导出的世界副本经原版读回时钟、居民坐标、目标风速和云数。其他物种、事件、天气画面和居民互动仍在补齐。

夜间与地牢入口的老人交谈可选择 Curse，召唤骷髅王。胜利前深入地牢会遇到穿墙追击的地牢守卫，击杀守卫会掉落骨钥匙。胜利后守卫停止刷新，可右键解救自然刷出的机械师，也可用起始近战武器击败愤怒骷髅并拾取掉落。F5 世界副本记录骷髅王和机械师进度，以及愤怒骷髅击杀数和旗帜领取资格。旗帜领取界面、其它地牢敌怪及机械师商店仍待接入。

普通 Classic 世界中，被绿史莱姆撞死会抛出墓碑。靠近后右键可读碑和编辑铭文。铜镐可拆下墓碑并拾回原款式物品。F5 写出世界与角色副本，原版 1.4.5.8 可读回碑文改动、拆除后的地块及拾回的物品。

Classic 下拆碑可能引来鬼魂。鬼魂会穿过地形追击，接触会掉血，能用起始近战武器攻击。鬼魂杀死角色会留下相应碑文，并从角色附近淡出。
